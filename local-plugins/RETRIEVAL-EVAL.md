# 召回排序合成基线

本基线只使用四条合成 L2，不读取真实用户数据、不调用模型或 Embedding 服务。它通过正式
`memory.search()` 路径比较词面命中和预先给定的语义候选，供后续 Reranker 改动做回归门禁。

当前固定结果：Hit@1 = 0、Recall@3 = 1.0、MRR = 0.5。存在一条不相关但置顶的记忆时，
它在四个查询中都排第一，四条目标记忆均位于第二。这不是生产质量结论，但明确证明当前排序中
“置顶绝对优先”会压过词面相关度和语义相关度。后续 Reranker 不得降低 Recall@3，不得把模型
生成文本写入记忆，并需先明确是否保留这一产品语义，不能在实现中暗改置顶含义。

0.16.0 的可选模型重排保留了该语义：置顶条目不进入模型候选并始终保持最前，只重排其余候选。
因此上述默认关闭基线数值不变。真实模型的相关性收益尚未评测，不能据此宣称质量提升。
