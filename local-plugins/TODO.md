# 插件系统待办

## 当前主线：复现本地 Cyrene-Agent

在引入新的产品设计前，优先用上游官方插件 API 在上游原生 Chat 中复现本地 `Cyrene-Agent`
的聊天、人格与记忆行为。Work、Code、Learn、朋友圈和外部渠道不属于当前验收范围。
对原项目与用户数据只读；开发、构建、测试及隔离宿主数据均限制在 `Cyrene-Agent-N` 内。

当前主线完成标准：

- 已确认本地功能清单及其真实调用链，不以界面或文档推测实现；
- 能由插件实现的功能完成迁移，并通过单元、构建产物和隔离宿主验证；
- 不能由官方插件 API 实现的差异单独列明，不用读取宿主私有模块等方式绕过；
- 完全不能仅靠插件实现的能力留到最后，再统一评估最小主程序改动；
- 真实数据测试保持显式、只读、隔离，不改变 activation、访问统计、DMAE 或源文件；
- 不因下面的后续优化改变当前数据格式、检索结果或注入语义。

当前实施顺序：

- [x] 完成后台屏幕观察：显式启用、内存态摘要、宿主像素无变化短路、变化降频、失败重试、停用即取消，并只向插件暴露文本摘要。
- [x] 完成主动消息基础闭环：接入屏幕摘要与锁屏/空闲状态、结构化静默决策、未回复限制、成功落盘回执和取消/过期保护。
- [x] 对齐本地主动消息的七个非天气场景评分、Desire/affinity、接话/下次开口时结算忽略反馈、第二条消息 55 分下限与重复文本抑制。
- [x] 天气场景：新增结构化、只读、带有效期且不暴露位置的 `weather-context` 宿主边界；插件按本地雨天、降温、舒适晴天评分公式生成候选。
- [x] 屏幕观察、主动消息与天气边界通过完整 Electron 隔离宿主验收；结果与隔离证据见
  [2026-09-20 验收记录](PROACTIVE-WEATHER-ACCEPTANCE-2026-09-20.md)。
- [x] 补齐近似空闲梦境的独立自动保存授权；默认关闭，只保存可撤销的插件私有叙事，不修改来源记忆。
- [x] 收口后台压缩交互：手动确认／达标自动压缩二选一，自动阈值 0.80，顶部展示最近 3 个压缩组，并兼容旧记录。
  完整验证与数据隔离证据见 [记忆压缩验收记录](MEMORY-COMPRESSION-ACCEPTANCE-2026-09-20.md)。

  自动化、完整 Electron 与数据隔离证据见 [主动消息忽略反馈验收记录](PROACTIVE-IGNORE-ACCEPTANCE-2026-09-20.md)。

## 后续优化：模型日程、日记与朋友圈联动

以下设计已确认可行，但按用户要求暂缓到屏幕观察与主动消息完成之后：

- [ ] 每个日程日以本地时间 04:00 为边界，读取前一日已确认日记摘要，单独调用一次模型生成结构化当日日程并写入插件私有存储。
- [ ] 程序未在 04:00 运行时在启动／唤醒后补生成；所有入口共用按日期 single-flight，避免重复模型请求。
- [ ] 当日日程通过官方 `moments-post` Prompt 来源单向提供给朋友圈发帖决策，不强制发帖，也不把日程声称为现实经历。
- [ ] 等宿主提供成功落盘的只读朋友圈事件后，再把已发布动态写入日记素材；禁止插件直接读取宿主 `moments.json`。
- [ ] 数据流保持为“日程 → 朋友圈素材 → 成功发布事件 → 当日日记 → 次日日程”，避免同日自我反馈循环。

辅助任务模型选择暂不列入近期实现：官方 `deps.llm` 尚未提供宿主模型档案选择接口，不读取宿主
私有配置绕过。对参考项目只借鉴思路，不直接复制代码。
