# 短期状态与未完话题验收（2026-09-20）

## 范围

本轮在 `companion-memory` 内复刻本地可选 `short_term/open_loop` 对话连续性。没有启动 Electron，
没有读取真实聊天、记忆、模型配置或 activation 数据；写入仅发生在当前 `Cyrene-Agent-N` 工作树。

## 行为

- 功能默认关闭，且独立于普通记忆自动提取、回复注入和 Moments 注入；启用时明确提示每个成功回合
  会增加一次宿主模型调用。
- 只处理轮次开始时冻结为 `companion`、最终助手消息已确认落盘的桌面 Chat；原生后端、旧宿主未标注
  后端、渠道、其他模式、取消、失败和未落盘回合均不处理。
- 模型输出只接受 `short_term` 或 `open_loop`，新增和关闭操作都必须带本轮用户消息中的逐字证据；
  每轮最多 4 个操作。关闭目标只能来自本轮查询实际召回的至多 3 条候选。
- `short_term` 有效 14 天，`open_loop` 有效 3 天；每会话最多保留 200 条 active。后续只在同一会话
  按相关度注入最多 3 条，明确回忆意图可以恢复已归档候选。
- 状态只写插件私有 `social-context-state`；不写宿主社交原子、宿主记忆或原始会话。可选 Embedding
  已启用时才尝试为新摘要建立向量并发送当前查询，失败回退到本地词面／时近度，不中断回复。

## 时间标签

动态 Prompt Provider 现在接收宿主已解析、校验后的 IANA 聊天时区；它不包含城市、坐标或系统位置。
连续性条目的“形成于”标签已按该字段格式化，与本地版跨时区行为一致。

## 隔离结论

所有测试数据均为合成消息和内存／`-N` 私有测试存储。测试没有连接真实模型或 Embedding 服务，也没有
启动任何 Cyrene 进程，因此不会改变真实用户会话、DMAE、访问统计、激活值或模型额度。
