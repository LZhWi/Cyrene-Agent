记忆始终保存在插件私有目录，不读写宿主 memory.json。可选择接入上游桌面 Chat；五个能力默认全部关闭。

上游原生聊天接入

各项权限独立保存。读取只接收启用后的成功桌面轮次，不扫描旧会话；自动提取才会把插件已保存的待处理轮次发给主程序当前模型；注入只在下一轮回复前提供相关插件记忆。

旧记忆来源绑定

只处理已导入且仍标为“未核对”的旧记忆叶子。压缩摘要不直接绑定某一句原话，而在全部子项核验后推导时间包络。先加载会话标题，再选择最多 20 个会话进行只读预检；不会修改宿主会话，也不会调用模型。唯一原文可批量确认，重复原文必须逐条选择。

旧记忆导入

预检只读解析指定 memory.json。实际导入仅写插件私有空库，源文件始终只读；保留有效 facets，但不导入向量、DMAE、梦境和维护日志。


  
旧向量索引

  
仅复制与已导入 L2 对应的 user_memory 向量；不复制聊天历史文本，不调用原 RAG，不更新访问计数。必须先完成上方旧记忆导入。

  

  

  
语义检索 Provider

  
默认关闭。启用后，每次检索仅向指定服务发送当前查询文本；不会发送记忆库。服务输出维度必须与导入索引一致。

  

    
    
    
    
    
    
  

  
新记忆语义索引

  
这是与查询外发分开的权限，默认关闭。启用时只把当前已有记忆记录为本地基线，不会上传；之后仅将新提取或手动编辑的可检索 L2 摘要正文发送给上方 Provider，不发送原话、证据或聊天历史。

  

    
    
  

  
既有摘要向量补建

  
先只读列出尚无当前向量的有效摘要，再选择本次范围。只有最终确认后才会把所选摘要正文逐条发送给 Provider；单次最多 100 条。

  
  

    
    
    
  

  
L0 稳定画像 / L1 近期状态

  
L0 锁定只阻止自动提取，仍允许手动修改。L1 超过来源时间 30 天不再自动注入。清空字段后保存即可移除。

  

  
画像变更确认

  
同字段的新表述不会自动覆盖旧值。请核对两份证据；过时候选不能覆盖后续编辑。处理记录会保留。

  
  
模型辅助候选重排

  
默认关闭，仅用于独立聊天和本窗口手动搜索。启用后会把当前查询与最多 12 条非置顶 L2 摘要发送给当前宿主官方模型服务；不发送原话、证据、历史或持久化 ID。置顶记忆仍保持最前，原生回复注入不会调用重排模型。

  

  
DMAE 工作记忆

  
默认关闭。启用后，仅在记忆实际注入独立聊天或上游原生回复时更新插件私有激活状态，使近期命中的 L2 最多跨 3 个未命中轮次驻留；手动搜索、预检和打开窗口不会更新激活值。不会调用模型或修改记忆正文。

  

  
L2 生命周期候选

  
默认不记录。启用后只在记忆实际注入聊天时保存插件私有的最后注入时间和次数；手动搜索、预检、原文读取及模型提取均不计入。预检仅把达到闲置期限的非置顶记忆列为候选；默认仍需人工确认，只有另行开启下方自动执行后才会每日按确定性期限降一级，绝不删除正文或证据。

梦境周期与人工反思

L2 事件记忆
归档会停止该条摘要注入，不删除原始对话；历史检索仍可能返回相关原文。

相似 L2 候选预检

L2 可撤销压缩复核

  
选择 2 至 5 条有效记忆。模型只提出是否可无损合并及候选总结，不直接修改；应用时保留原条目并标为 merged，之后可在未发生其他修改时撤销。

  

  

  

  
L2 Resolver 双条复核
仅检查选中的两条，不扫描全库。新结果区分无关、上下文差异、偏好演进、直接冲突和证据不足，并可提出创建总结与状态变化计划；模型不直接执行，需用户确认，且可在没有后续变化时撤销。旧格式复核记录继续兼容。
