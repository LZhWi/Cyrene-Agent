# 昔涟桌面 HUD 0.8.7

作者：Noimpty。原仓库：[Cyrene-Agent-Plugin / codex/cyrene-hud-upstream](https://github.com/LZhWi/Cyrene-Agent-Plugin/tree/codex/cyrene-hud-upstream)。上游提交版的完整使用与数据处理说明见 `README.upstream.md`，打包时作为兼容版的 `README.md`。

0.8.7 性能采集由主进程定期执行：收起或隐藏时每 5 秒采集，展开时目标间隔为 1 秒，并立即请求一次更新；不依赖后台页面计时器。耗时采集不并发堆积，实际刷新受系统查询耗时影响。渲染页接收最新快照，展开后的状态与心情读取间隔也缩短为 1 秒。仅时间指标与 UI 模拟测试期间不采集硬件；禁用插件停止采集。

0.8.6 将外壳、通知和详情动画缩短为 300 ms，沿用无回弹的三次缓动；设置页「显示内容」右侧增加 ⓘ 按钮，五段使用说明默认隐藏，点击以注释形式展开，再次点击收起。

0.8.5 将外壳、通知和详情动画改为 400 ms 的 ease-in-out cubic：开始、结束明显减速，中段加速，不再回弹或超出目标。改变目标时从当前尺寸接续，通知转 HUD 直接过渡；上边缘仍固定。减少动态效果时直接切换。

0.8.4 移除收起胶囊右侧的消息图标；通知缩回后仅在 HUD 头像角标上显示未读。悬停模式下胶囊、通知和 HUD 共用固定的上边缘，展开收缩只向下变化高度。外壳的 spring 动画放慢并增加约 3.7% 的轻微回弹，详情与圆环位移也略放慢；减少动态效果时仍直接到达目标尺寸。

0.8.3 去掉 HUD 和通知外壳轮廓线，头像未读角标改为实心圆、空心数字。毛玻璃窗口只在几何或层级变化时更新；使用原生遮挡检测恢复置顶，避免稳定背景上每秒无条件重新置顶、每 100 ms 重排毛玻璃窗口。

0.8.2 去掉收起小胶囊的轮廓线，三个点固定使用深色背景配色 #f5d3e0；展开 HUD 或通知时，轮廓随 spring 进度恢复。

0.8.1 在设置页加入「UI 效果测试」：按已保存的外观和圆环顺序模拟头像/圆环悬停、鼠标移开、主动消息通知，或依次演示全部。沿用实际 spring、停留与移开计时逻辑，不移动系统鼠标。测试使用固定的硬件/状态示例和独立的临时未读数，不发送消息、打开会话或写入真实未读；真实消息仍正常记录。停止、保存设置、关闭设置页或 60 秒无操作后恢复正常模式。持续显示用户测试时临时使用胶囊模式，结束后恢复。

0.8.0 接入主动消息通知：监听宿主 `chats:changed`，只通过既有会话列表和分页接口读取 `proactive-chat` 中新增的助手文本。收起时胶囊展开为头像、标题和单行摘要，停稳显示 2 秒后缩回，并在右侧保留消息标记；HUD 展开时头像右上显示透明底未读数字（超过 99 显示 99+）。正在查看 HUD 时只更新角标；连续消息更新同一张通知并重新计时。

未读由插件单独记录，并保存最多 100 字摘要及消息标识；首次启用跳过旧历史，重启不重放已通知消息。点击通知、消息标记或数字角标打开已有主动消息会话，成功后只清除此次打开前的未读；打开失败或同时到达的新消息不会被误清除。普通头像的自定义入口保持原设置。宿主当前没有共享已读接口，在其他窗口直接阅读不会自动清除 HUD 未读。两版均不新增主程序接口，不发送消息或调用模型；设置窗口不读取通知内容。

0.7.0 悬停模式常驻顶部中央 48×10 px 三点小胶囊。停留达到所设时长后，由同一个外壳通过 spring 动画展开为 HUD；离开触发区域和外壳、计时结束后缩回。收回途中返回可反向展开，收起时暂停硬件和状态读取。胶囊沿用底色、透明度及自动配色，原生圆角模糊跟随同一帧几何，动画不改变透明窗口画布大小；减少动态效果时直接切换。云母在悬停模式使用圆角毛玻璃，持续显示仍使用系统云母。

0.6.12 原生毛玻璃辅助窗口在创建时明确加入置顶窗口组，修复 Electron 内容层正常置顶、模糊层却留在普通应用下方的问题。保留原有 24 DIP 高斯模糊、圆角裁剪、自定义底色、固定画布和不抢焦点设计；隔离 Chromium 应用窗口的动态条纹对照验证实际模糊，不再仅以桌面背景或均匀底色判断效果。

0.6.11 浅色模式的环内文字改为深灰 #514955，详情主文字改为 #403b44、小字改为 #58515c，GPU/风扇/网速详情的两行仍保持一致。未占用轨道在原自适应浅灰基础上提亮；占用环和深色模式保留原有颜色。

0.6.10 收窄浅色配色的自适应幅度：占用环和中心文字保持清晰的粉色，背景变亮时仅适度提亮；轨道限制在可辨识的浅灰范围，避免随灰色背景变暗。保留 250 ms 颜色过渡及内外环同色。

0.6.9 浅色圆环根据 HUD 底色亮度自适应：未占用轨道比底色略深，占用环和中心文字使用同一柔和粉色，灰色和近白色底色下分别调整明暗。沿用收起时固定区域的空白边缘采样，采样包含已经混合的背景色；没有采样时按用户背景色计算。颜色以 250 ms 过渡，减少动态背景下的突变；深色配色、背景颜色及透明度配置保持原有设置。

0.6.8 双环内外圈的占用部分使用相同颜色和不透明度，浅色未占用轨道改为浅灰色 #d8d2d7；圆环中心文字使用占用部分的颜色，包括网速的上下行数字和箭头。深色轨道保持原样。

0.6.7 GPU、风扇及网速展开详情的上下两行统一字号、字重和颜色：13 px、500 字重，浅色使用 #4f4a57，深色使用 #f6e8ee；移除第二行额外的顶部间距。圆环中心的网速仍保持 8 px。

0.6.6 风扇 CPU/GPU 转速行统一为 13 px，网速圆环中心数字及箭头缩小为 8 px、收紧行距。指标详情与头像的状态、心情详情保留完整文字的宽度和位置，按 spring 位移逐步揭示，揭示边缘使用最多 16 px 的透明渐变；不再用省略号或整体淡入表示展开，收缩时反向遮回。

0.6.5 GPU 有已识别的独立显存数据时使用双环：外环为 GPU 使用率，内环为显存使用率；当前通过 NVIDIA 采集器识别独立显存。没有可靠显存数据、WMI 汇总或采集失败时保持单环，不把共享内存当成独立显存。

所有性能详情和头像的状态、心情详情均按浏览器实际字体测量文字宽度，加少量留白；内容变化时沿原 spring 动画调整宽度。头像只遮盖实际文字区域重叠的圆环，长文字超出屏幕可用空间时裁切，外壳左边仍固定。

新增可选风扇圆环。按 CPU、GPU、辅助风扇顺序选择最多两个可读传感器，一个使用单环、两个使用双环；已读到的 0 RPM 显示为停止，不算缺失。百分比按当前 RPM / 用户配置的 100% 参考 RPM 计算并限制在 0–100%，每种风扇可独立设置，默认使用本机实测的 6300 RPM 作为参考值。接口没有返回实际满速值，因此此值是相对参考值，不是固件报告的转速百分比。展开显示每个风扇的实际 RPM，不控制风扇、不主动校准满速。网速圆环收起时上下显示上传、下载数值及方向箭头，省略 MB/s 单位；展开详情保持原样。

支持通过已安装的华硕 ATKACPI 驱动读取 CPU 温度，在 CPU 详情第一行显示，第二行仍显示频率。独立辅助进程只允许固定的 DSTS 温度查询（端点 0x00120094）和三种风扇转速查询（0x00110013、0x00110014、0x00110031），没有控制风扇、功耗或性能模式的接口；本机普通权限读取成功，不安装驱动。不支持、无权限或返回异常值时不显示对应读数，所有传感器均不可用时退避 30 秒。接口常量及返回格式核对了 [G-Helper 的 ASUS ACPI 实现](https://github.com/seerge/g-helper/blob/main/app/AsusACPI.cs)，未引入其控制功能或代码依赖。

0.6.4 背景亮度固定采样收起时外壳的上下留白区域，18 个采样点不随详情展开宽度移动，仍每秒采样一次。深浅配色使用统一亮度阈值，同样亮度不再因之前的配色而给出不同结果。移除头像和性能指标的原生鼠标提示框，保留悬停展开详情和无障碍描述。

HUD 唤出时重新设置置顶并抬高层级，可见期间每秒维护一次，恢复被其他置顶窗口覆盖或置顶标记丢失的情况；隐藏时不维护，不激活或抢占焦点。

0.6.3 固定外壳左边在收起时的位置，所有指标及头像详情只向右展开，收缩也不移动左边。收起状态仍顶部居中；小屏幕预留右侧展开空间并自动缩小。展开期间其他圆环沿同一 spring 时间线移动。

纯色、通透和毛玻璃使用固定透明画布；动画只修改画布内的外壳尺寸、内容位置及圆角模糊裁剪，不逐帧改变 Electron 或原生毛玻璃窗口大小。云母是 Electron 整窗材质，仍按外壳宽度调整窗口，以免透明空白染上材质；左边同样固定。隐藏计时和鼠标命中范围按可见外壳计算，透明空白不属于 HUD。毛玻璃就绪及首次电源状态通知不会在材质未变化时重置展开动画。

0.6.2 试用版收紧详情：保留原圆环，展开时中心由名称淡入百分比，旁边仅放两行信息。内存显示名称与已用 / 总容量；CPU 显示系统报告频率（无频率时显示型号）；GPU 显示温度与显存；网速显示上传、下载；电池显示供电状态；时间显示日期与完整时间。各项按内容使用不同宽度，内存额外展开宽度从 190 px 缩至 128 px，默认三圆环展开内存时外壳为 384×60 px。

动画保留 spring 连续计算，绘制尺寸统一落在窗口的像素网格上；只在实际边界变化时调整窗口，毛玻璃合并积压的旧尺寸命令。布局移动不会自行触发新的悬停项，减少快速切换和收起时的抖动。上传、下载复用原有网卡计数采样，不增加采样命令；CPU 频率使用系统报告值，不提供没有数据源的 CPU 温度或电池剩余时间。

0.6.1 暂时只开放顶部居中，其他位置在设置页禁用；读取旧配置和保存设置时统一使用顶部居中。显示器仍可选择。本版尚未改动展开动画的锚点策略，动画过程中外壳持续对齐屏幕中轴的方案待接入。

0.6.0 试用版改为头像与多个性能圆环。可勾选 CPU、内存、GPU、网速、电池和时间，拖动或使用上下按钮调整顺序。新配置默认内存、CPU、GPU；旧配置保留原单指标，更新后在设置页勾选其他指标即可。至少保留一个圆环；未知指标和重复项不会进入配置。没有可用百分比的网速使用虚线环，不虚构占用率。

圆环中心显示名称，收起时保持 12 px 间距，外壳按内容收紧；默认三个圆环的外壳为 256×60 px。已移除宽度设置入口，旧宽度不影响自动布局。悬停 150 毫秒展开该项详细数据，移开 200 毫秒收起；圆环及详情属于同一悬停区域。外壳宽度和其他圆环的位移由同一 spring 时间线计算，悬停的圆环尽量固定在鼠标下，屏幕右侧改向左展开。四种背景模式使用同一布局；毛玻璃边界跟随相同动画尺寸，亮度仍每秒采样，不随动画增加采样频率。系统减少动态效果时直接切换到目标尺寸。

悬停头像时向右侧显示主程序已有的状态与心情，优先利用现有外壳空间，空间不足时才适度扩宽，重叠圆环临时隐去；详情也属于头像悬停区域，移开后恢复圆环。使用 `runtime-state:get` 和 `model-config:get` 两个固定只读入口，仅向页面投影状态、心情和必要布尔标记，不提供配置或历史。同步关闭、接口缺失时明确提示，插件不触发模型请求。

移除了开始计时条件选项。现在统一在鼠标离开顶部触发区域和 HUD 窗口后开始收起计时；返回任一区域取消计时，再次移开重新计时。旧 `hideTrigger` 配置自动忽略，不再保存。持续显示不自动收起，原有显示时长和唤出停留时间继续可调。

0.5.1 修复已有 Chat 会话的筛选：允许选择“昔涟的主动消息”等 `proactive-chat` 会话，仍只向插件设置页返回 ID、标题和模式。上游兼容版打开设置时优先使用上游入口；仅当该入口没有注册时，回退本地项目已有的 `sidebar:open-settings` 事件，不需要给主程序补兼容接口。兼容版也可在本地项目使用，窗口按该宿主的 Chat / 工作窗口划分打开；本地版的筛选修复需重启更新后的主程序。

0.5.0 增加头像快捷入口：不操作、Chat、Work、Code、Learn、设置。四种会话模式可选择指定已有会话或每次点击新建空会话。默认不操作；头像点击是鼠标穿透的局部例外，其余区域保持原配置。不会发送消息、调用模型或注册模型工具。已有会话失效时提示重新选择，不自动创建替代会话。

提供两套互斥安装包，插件 ID 均为 `cyrene-hud`，替换安装保留配置：

- `cyrene-hud-local.zip`：需本地新增 `window-navigation` 宿主能力。Chat 使用聊天窗口；Work、Code、Learn 使用工作窗口。导航接口只返回会话 ID、标题和模式，不提供消息内容。
- `cyrene-hud-upstream.zip`：无需改主程序，不声明新能力。依据上游提交 `9fcff7a3b5106af6a6c60e35a94cfe95630463af`，仅复用 `chats:list`、`chats:create`、`chats:open-in-react-window` 和 `settings:request-switch-section` 四个固定入口；四种模式按上游规则使用统一聊天窗口。宿主升级后需重新验证这些内部 IPC 的兼容性。

`cyrene-hud.zip` 是本地版的同内容副本。安装本地版前需使用更新后的主程序；上游版适用于当前上游。新建会话沿用宿主默认模型档案，但不触发模型调用。代码、学习会话的工作区绑定仍由宿主页面正常选择。

0.4.15 支持设置移开后的显示时长（0.1–60 秒），默认 4 秒。可选择鼠标离开触发区域后开始计时，或同时离开触发区域与 HUD 窗口后开始计时；返回所选区域会取消倒计时，再次离开重新计时。默认只检查触发区域，延续已有行为；鼠标穿透开启时也可检测窗口区域。预览使用同样的时长与计时条件；持续显示模式不自动隐藏。

0.4.14 支持设置鼠标唤出的停留时间，默认 0.35 秒，可调整为 0–10 秒；提前离开顶部中央区域会取消本次计时，再次进入重新计时。设为 0 秒时立即唤出；预览按钮仍立即显示，移开后约 4 秒收起。已有设置缺少停留时间时使用 0.35 秒。

0.4.13 将当前使用的配置设为默认：内存、顶部居中悬停唤出、主显示器、408×60 px、30 px 圆角、毛玻璃、底色 #f9f4f8、底色不透明度 20%、内容不透明度 80%、缩放 100%、鼠标穿透。已有保存的设置继续优先使用。

0.4.12 毛玻璃改为直接背景采样与显式 24 DIP 高斯模糊，修复 QQ 主窗口文字仍清晰透出的兼容问题；保留圆角裁剪、自定义背景色、自动配色和鼠标穿透。真实 QQ 标题、局部覆盖及内容区已做通透/毛玻璃对照。

0.4.11 圆环放大约一成、线宽略微加粗并右移 3 px，颜色调淡。大数字在深色背景下跟随小字颜色，浅色背景下使用柔和灰色。

0.4.10 大数字字号缩小约一成，内存容量改为 20 px；保留原有布局尺寸。

0.4.9 修复 Windows 节能模式下原生毛玻璃退成黑底的问题：节能时自动使用通透背景，保留所选颜色和透明度，设置页显示原因；退出节能后自动恢复原生模糊。不会更改系统节能开关或保存的背景模式。

0.4.8 下调自动配色阈值，修复灰白背景仍保留深色配色的问题。头像、文字与圆环统一按可见背景亮度切换；深色背景使用白色读数、浅色说明和亮粉色圆环。亮度低于 130 切到深色配色，升至 145 恢复浅色配色，保留切换缓冲。

0.4.7 头像根据 HUD 可见背景的亮度自动换色：浅色保持原粉色，深色使用亮粉色 #FFC0D8。Windows 11 22H2+ 的毛玻璃、通透和云母模式每秒在 HUD 内空白处读取六个像素，包含颜色遮罩的最终效果；临时像素缓冲立即释放，只向本插件传递亮度，不保存图片或接入模型。隐藏时暂停。使用明暗阈值缓冲避免临界亮度来回切换；纯色及采样不可用时按配置的背景色判断。

独立透明置顶窗口，提供 CPU、内存、GPU、网络、电池和时间预设。当前仅开放顶部居中，支持选择显示器、缩放、不透明度、鼠标穿透，以及持续显示 / 顶部中央鼠标唤出（移开后约 4 秒收起）。点击插件卡片的“打开”进入设置；先保存再预览。

界面沿用主程序珍珠白主题的浅粉背景、白色卡片、粉色强调色、字体栈和圆角控件，复用主程序的昔涟头像图标。相关样式随 ZIP 打包，不依赖宿主内部文件路径。

外观设置支持高度 60–320 px、圆角 0–160 px，以及原有整体缩放和不透明度。宽度按圆环内容自动计算，超出显示器时自动缩小；旧宽度配置不参与新布局。背景可选珍珠白纯色、通透（不模糊）、原生毛玻璃（支持圆角的背后窗口模糊）、系统云母（壁纸色调，不是实时窗口模糊）。

毛玻璃使用随包附带的 `GlassHost.exe`（源码在 `native/GlassHost.cs`），由 Windows.UI.Composition 背景采样画刷、Direct2D 高斯模糊与圆角裁剪实现，无需 Win2D 依赖；没有使用截图回传渲染。云母仍使用 Electron 原生材质，只支持直角。两种系统背景需 Windows 11 22H2+，毛玻璃辅助程序为 Windows x64 / .NET Framework 4.x。启动失败会回退纯色，设置页显示提示；切换为纯色保存后可重新选择毛玻璃重试。节能时使用通透背景并暂停模糊。

背景颜色支持自定义，并提供独立背景色不透明度。纯色模式使用不透明底色；透明、毛玻璃和云母使用指定透明度的颜色层。颜色层不降低文字透明度，深色底色自动搭配浅色文字。原有内容不透明度仍影响 Electron 的文字与颜色层，原生模糊底层独立绘制。未引入 TranslucentTB 代码，也没有向模型增加接口。

原生绘制窗口随 HUD 显示、隐藏、移动和缩放；通透、云母模式仅运行隐藏的亮度采样辅助窗口，不绘制毛玻璃。切换纯色或禁用插件时终止辅助进程，宿主窗口关闭或控制管道断开时辅助程序自行退出。
只需安装并启用 cyrene-hud.zip，硬件采集器已内置，不依赖独立 system-status 插件。采集失败会清空旧值并自动重试；时间可独立使用。主进程在 HUD 收起或隐藏时每 5 秒采集，展开时按 1 秒目标间隔采集；实际间隔不短于查询耗时，动画与采样分开。

插件默认停用，不注册 AI 工具、Prompt Provider，不声明模型、会话、记忆或屏幕观察服务。HUD 的沙箱 preload 仅暴露自身的硬件快照、设置、投影后的状态心情及固定头像导航接口；不提供通用 IPC、Node、网络或 shell 给页面。硬件状态不会自动送给模型。此隔离指本插件的接入路径，不表示能阻止用户主动截图或其他已有工具读取屏幕。

设置保存在插件私有存储；禁用 HUD 会统一销毁 HUD、设置窗口及原生模糊窗口、计时器、显示器监听器，清理数据 IPC 并中止采集。HUD 依赖宿主运行，退出 Cyrene 后退出。

Windows 使用 Node 系统接口、PowerShell/CIM 和可选的 nvidia-smi。CPU、网络首次采样没有差分基准，返回 null；主进程定期采集绕过完成缓存，进行中的查询合并，页面读取最新快照不重新采集。NVIDIA 读取 GPU 0；不可用时 GPU 使用率回退 WMI 引擎总和（夹紧至 100%，属于估算），温度和显存保持 null。CPU 温度和风扇支持固定 ASUS ATKACPI 查询，不支持的设备显示未知；不读取功耗。网速是全部网卡的收发合计，虚拟网卡可能重复计数。PowerShell 超时 8 秒，nvidia-smi 超时 3 秒。

从 0.1.0 更新时导入同名新版 HUD，保留原有 HUD 设置。之前的独立数据源不再需要，可以停用；此更新不会自动卸载其他插件。上游 system-status 的采集代码来源和 MIT 许可保留在 NOTICE.md / LICENSE，本插件没有包含上游的两个模型工具。

构建使用本机 Windows 的 .NET Framework 编译器及 WinMetadata，生成原生辅助程序并随 ZIP 打包；用户使用时无需安装编译器。构建（从 local-plugins 运行）：`node scripts/build-cyrene-hud.mjs`。交付时加 `--release`，写入独立的 `releases/cyrene-hud-版本号`；原生测试同样加 `--release` 即可验证此目录。
