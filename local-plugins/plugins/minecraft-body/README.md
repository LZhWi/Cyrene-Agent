# Minecraft Task Controller V1 / 0.4.0 预览

在原 0.3.0 身体插件内扩展，不另起模型、训练、人格、记忆或网络服务。默认关闭，启用不连接服务器；必须先在面板手动连接。三项宿主工具：`minecraft-body_start_goal`、`minecraft-body_task_status`、`minecraft-body_cancel_task`。新增工具由宿主按 `input-control` / `external_side_effect` 处理；不需要 `llm` 服务依赖。工具返回目标状态，不把收礼或制作成功称作学会技能。

## 可执行目标

V1 只支持橡木链到 `wooden_pickaxe` 总量 1（不是再制作一把）；`equip` 默认 true，最后实际背包和实际手持都须满足。仅主世界、显式最多每边48格区域；采集/放置分别 opt-in。已有材料优先，只有缺量才补；合成按已连接协议的 minecraft-data 配方完整依赖闭包规划，并在实际动作中检查可用配方。背包不足不等于版本不支持。每次只执行一步，随后重新观测实际状态再规划。

调用 `start_goal` 示例（坐标须改为你测试场地的实际允许范围）：

```json
{"item":"wooden_pickaxe","desiredTotal":1,"equip":true,"allowedRegion":{"dimension":"overworld","min":{"x":-8,"y":63,"z":-8},"max":{"x":8,"y":70,"z":8}},"allowCollect":true,"allowPlace":true,"timeoutMs":120000,"actionBudget":16}
```

区域还须包括路径、放置支撑及当前站位；未知路径可达性由运行时动作验证，禁止挖掘/搭建寻路。允许采集不代表允许破坏任意方块，只采白名单橡木目标；没有安全目标/位置、材料、权限或预算就 blocked。服务器插件、自定义配方/领地权限无法完整探测，因此不宣称自定义服兼容；V1 仅面向受控 Vanilla 测试环境。已在独立 Vanilla 1.21.11 临时超平坦测试世界完成下述受控实服验收，不代表随机生存环境通用可靠。

## 互斥、停止与恢复

start_goal 返回后任务在后台持续到完成/阻塞/取消；停止聊天生成不会自动停止它，须调用 cancel_task、面板停止任务/动作或断开身体。

同一身体只有一个任务租约。手动动作、其他任务、自动生存动作不能插队；危险状态仍能中断。取消后底层调用可能仍 draining，槽位和运行时租约不会提前释放。断线/超时不重发；`effectsUncertain` 阻止新任务，须用户查看实际世界/背包，待身体静止或显式断开后，在面板点击“已核对现场，确认不确定效果”。此确认不恢复旧任务；需新建目标。状态工具不能静默解除不确定状态。插件重启把未完任务记为 interrupted，不自动连接或重放。

仅在宿主分配插件目录 `tasks-v1/` 保存当前状态和 JSONL。事件含 task/action ID、动作意图、前后任务相关观测、结果/错误、时间和预算。日志约4MiB轮转、最多3份；不保存主人/附近玩家、聊天、完整配方图或宿主私有记忆。磁盘写失败会停止任务，不继续未记录动作。轮转意味着不保留无限历史。

## 本轮自动验证

详见 `VERIFICATION.md` 和 `tests/live/2026-10-20-summary.json`。本轮包含32项 TypeScript、64项运行时测试及构建/ZIP隔离检查，另有官方 Vanilla 1.21.11 实服受控验收：空背包、四块橡木、无工作台，连续三轮完成采集→拾取→合成/放工作台→木镐→实际手持，每轮14动作；采集/放置未授权零动作阻塞、动作中取消与不确定效果栅栏、等待静止后确认、区域外拒绝均通过。

## 原 0.3.0 身体文档（历史基线）

# Cyrene MC 身体（0.3.0）

这是独立的 Minecraft Java Edition 身体插件，默认关闭。启用插件也不会自动连接服务器。通过设置面板手动连接与操作，可选身体自身的生存反射；原0.3.0不注册工具、提示词、渠道、事件订阅或 LLM 调用（0.4.0工具扩展见上文），不读写 Chat、Companion、记忆或旧 GameBot 的运行数据。

已实现：连接/断开、位置和背包快照、过来、持续跟随、安全表面采集、合成、投出物品、拾取、进食、沿安全点撤回、停止动作、低血量/危险环境中断。跟随返回 `active`，到期后停止；过来必须核验实际距离；采集区分方块移除和物品入包；投出物品不声称主人已拾取；拾取须同时确认掉落实体消失和背包增加。

日常动作共30项，均从独立面板或插件 IPC 提交：

| 类别 | 动作 |
| --- | --- |
| 陪伴与移动 | 过来、跟随、指定位置移动、设家、回家、看向主人、沿安全点撤回、一格浅坑垫脚脱困 |
| 背包与装备 | 拾取、投出物品、手持物品、穿更好的护甲、副手盾牌、安全进食 |
| 采集与基地 | 表面采集、合成、放置普通建材/火把/工作台/熔炉/箱子、烧炼、木门开关、绑定箱子、查看箱子、存入、取出、绑定床、睡觉、起床 |
| 农耕与保护 | 开垦临水土地、种植、收割成熟作物、单目标近身自卫 |

家点、箱子和床只记在当前连接内，重生保留，断开重设；标记带维度，不自动跨维度或传送。移动和标记目标限32格内已加载地形。装备护甲按材质等级比较且须耐久可用，不评价附魔，同级或更高的已有护甲不替换。

箱子先显式绑定8格内最近普通箱子；存取单堆1..16件，同时核验窗口中玩家槽和箱子槽的数量，存入仍保留三块逃生材料。放置目标为8格内整数方块坐标，必须空闲、无实体、有安全支撑；只放一块白名单材料或设施，不铺大平台或生成建筑。睡觉仅允许主世界已绑定床，核验入睡位置及真实睡眠状态。

农耕只在主世界8格内临水空闲土地、空耕地或成熟作物上操作，支持小麦、胡萝卜、马铃薯和甜菜；需要可用锄或种子，寻路避开耕地，不操作玩家脚下的地块。收割、拾取、补种分为独立动作，收割计数不冒充入包数量。

烧炼支持原铁/铜/金、沙子→玻璃、圆石→石头、常见肉类、马铃薯、橡木→木炭；使用背包煤或木炭，8格内普通熔炉须三槽清空且未燃烧，成品取入背包才完成。每件通常需约10秒，数量16件需给足期限（最多300秒）。中断后物品可能留在熔炉并继续烧炼，必须先查看再决定后续操作。

近身自卫需要耐久足够的剑，只处理6格内一个白名单敌对生物，追击不超过初始位置8格，检查方块遮挡，收到死亡事件才确认击败；不攻击玩家、狼等宠物、中立生物、苦力怕或 Boss，不能保证动态战斗安全。浅坑脱困只支持一格深、头顶空闲且有安全出口的坑：起跳、消耗一块垫脚材料、确认落地，再走到出口。深坑、岩浆和复杂搭块路线不在此能力内。

拾取搜索八格内掉落物，数量参数限制掉落实体数（1..16），每堆可能含多件物品，实际入包数量看背包变化。进食排除腐肉、河豚、蜘蛛眼、毒马铃薯、迷之炖菜、生鸡肉与会传送的紫颂果。安全点仅保存在当前出生周期内，须有地面、身体/头部空间和至少一个相邻可通行位置；撤退前再次检查地形，沿已记录路线返回，不挖掘或搭块。

“自动生存”默认关闭，连接时生效。开启后：空闲且饥饿值低于14时吃安全食物；生命值不高于6时中断普通动作，有可返回安全点才尝试撤退。使用同一个动作槽，未结束的底层调用仍阻止新动作；自动尝试间隔15秒，手动停止会暂停自动生存30秒。无法保证战斗、岩浆、深坑或路线被破坏时安全脱困。

动作有独立 ID、截止时间、前后快照、背包变化和结果。结果包括 `submitted`、`active`、`completed`、`partial`、`failed`、`cancelled`、`timed_out`、`disconnected`、`rejected`。世界修改调用发出后若中断，`effectsUncertain` 表示需要查看实际状态，不能盲目重试。取消后底层调用未结束时显示 `draining`，阻止新动作；卡住可手动断开。不会自动重连、恢复动作或重放请求。

采集数量为已确认移除的方块数（1..16），仅限主世界表面、24 格搜索，另支持裸露煤矿、铁矿和铜矿；不挖脚下、不主动下洞、不让寻路破坏/放置方块。复用旧 bot 的材料/合成别名、工具耐久选择、环境危险判定、三块逃生材料保留规则，并参考其拾取、进食、安全路线、箱子、床、农耕及烧炼实现。复杂采矿、大型建筑、舟船、交易、附魔、视觉和旧 sidecar 的独立 Soul/Planner 未引入。

## 使用

在 Cyrene 插件管理中导入 `local-plugins/artifacts/minecraft-body.zip`，手动启用，打开设置面板，填写主人游戏名、服务器、登录方式，再连接。离线登录只能进入支持离线身份的服务器；正版登录使用微软设备码，凭据缓存仅保存在宿主分配的插件数据目录下 `microsoft-auth/`。断开后不会自动重连。第一轮应在测试服验证，勿直接用重要存档测试采集。

此阶段不自动发送游戏聊天，不把任何游戏聊天当作命令。`ai_chat_websocket`、Companion 共用人格/记忆和宿主高层规划留到单独授权的下一阶段。

## 一次性手动验收

自动验收使用新世界和临时玩家，未替你运行下面的手动体验。手动验收可集中在同一次游戏会话完成。

1. 在 Java 1.21.11 新建可用命令的测试世界，开放局域网并记下游戏显示的端口；或使用独立测试服。使用新世界或副本，保留原存档。主人可切创造模式搭测试设施，机器人须用 `/gamemode survival Cyrene` 保持生存模式；创造模式放块不消耗物品，不能通过本插件的消耗核验。
2. 导入本 ZIP、手动启用，设置 `127.0.0.1`、局域网端口、你的游戏名、机器人名 `Cyrene`、协议 `1.21.11`。离线身份仅用于允许此身份的测试服；服务器若需要正版身份，须改用微软登录。先不勾自动生存，再连接。
3. 在平整地面给机器人测试材料：木头、圆石、面包、钻石一件、剑、四件护甲、盾牌、锄、种子、火把、工作台、箱子、熔炉、原铁和煤。可以丢物品让它拾取，或在测试世界用 `/give Cyrene <物品ID> <数量>`。另放一张主世界床、一扇木门，并准备临水泥土地块及成熟/未成熟作物。
4. 按下表集中体验。面板会显示最近动作是已完成、部分完成、失败或已停止；展开详细状态可看背包、装备、前后快照和实际数量变化。每个动作结束再启动下一项，失败时先看原因及现场。

| 验收组 | 一次会话中的操作 | 应观察到 |
| --- | --- | --- |
| 陪伴 | 过来；跟随你走一段；停止；看向主人 | 实际靠近、跟走；停止后不再追随；头部看向你 |
| 导航 | 安全位置设家；指定32格内附近坐标；回家 | 实际到达并返回；远处、未加载或危险目标应拒绝 |
| 背包装备 | 拾取掉落物；手持铁剑；穿护甲；装备盾牌；三格内投出钻石 | 看见物品入包、手持和装备变化；投出不等于你已拾取 |
| 采集制作 | 采一块表面泥土/原木；合成木板；有工作台时合成工具 | 方块确实移除；背包实际出现成品；缺工具或缺材料说明原因 |
| 设施 | 选空格整数坐标，分别放火把、工作台、箱子和熔炉；开/关木门 | 指定位置确实出现设施，物品减少；门状态改变；占用格拒绝 |
| 箱子 | 绑定；查看；存入一件钻石；再取出 | 箱子和背包两侧数量一致；三块逃生材料不会被存光 |
| 睡眠 | 绑定床；测试世界 `/time set night`；睡觉；起床 | 实际躺下与起身；白天或不允许睡觉时如实失败 |
| 农耕 | 开垦临水土地；种小麦；只收成熟小麦；拾取；再补种 | 土地与作物状态改变；幼苗保留；不会把收割数说成入包数 |
| 烧炼 | 空熔炉、原铁和煤；烧炼铁一件，期限30秒以上 | 原料与燃料减少，铁锭进入背包；取消后先看熔炉剩余物品 |
| 生存 | 饥饿后手动吃面包；走出一段已记录安全路线后撤回 | 实际饥饿值增加并消耗面包；回到安全点，改坏路线则停止 |
| 自卫脱困 | 测试场景用一个近身敌对生物；另进入一格浅坑并垫脚脱困 | 有剑才攻击目标，低血量停止；浅坑消耗一块材料并走出，深坑拒绝 |
| 自动生存 | 断开后勾选自动生存再连接，准备面包和安全路线，测试饥饿/低血量 | 空闲时自动吃、低血量停止普通动作后撤回；手动停止暂停自动生存30秒 |
| 生命周期 | 跟随中停止、断开；在测试世界死亡重生 | 不重连、不重放旧动作；家/箱子/床重生保留，断开后重设 |
| Chat 隔离 | 在游戏聊天说“跟随”等命令，同时正常使用原聊天界面 | 游戏聊天只显示，不自行执行动作；当前 Chat 行为保持原样 |

重点看跟随是否自然、设施操作是否顺手、错误提示是否能定位现场问题；协议边界、取消与数量核验已有自动测试。验收结束点停止动作、断开连接，关闭测试世界。
