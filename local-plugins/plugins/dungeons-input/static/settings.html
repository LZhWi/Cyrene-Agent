初代地下城：原生键鼠 + 虚拟 P2
独立输入与营地短距离跟随测试。游戏请从 Xbox 应用正常启动，进入离线游戏；本工具不会启动游戏或编辑存档。

1. 检查驱动 → 在此面板创建两只手柄 → 再启动初代游戏。初始化会发送一个单位的摇杆值后归零，确认归零才显示就绪，不按按钮。
2. 按游戏提示，用第一只手柄初始化 P1（仅在需要时），用第二只加入 P2、选择测试角色。
3. P1 继续用原来的键鼠；第一只手柄保持空闲。测试第二只脉冲，确认只动 P2。
每次执行后，在倒计时结束前切回初代游戏；未切回则取消，不会补发。

菜单快捷操作（仅在角色选择、设置等菜单中使用）
手柄通常用 A 确认、B 返回，方向键移动焦点；屏幕 Enter / Esc 是键鼠提示。此处仍发送手柄按钮，不发送键盘键。角色选择时把焦点移到「完成」后确认；具体作用以游戏当前菜单为准，战斗中的 A/B 有其他作用。

快捷操作使用上方所选手柄、按住时间和倒计时，每次只发送一次；点击后请切回游戏观察。

营地短距离跟随（实验）
先点「只观察」，在上方倒计时内切回游戏；返回面板核对预览中的 P1/P2 框。只读取初代前台窗口，画面仅在本机内存中使用。识别失败请停止，不会使用旧位置。

跟随固定控制第二只手柄，与上方手动选择无关。每轮先右移、上移各 150ms 测量方向，再最多六次 150ms 短移；每次归零并重新观察。到达、受阻、丢失标记、失焦、F12 或期限结束都会停止，不自行恢复。此版不会绕障或战斗，也不能完整识别菜单；本轮保持营地空地，需要打开菜单或进关卡时先按 F12。
