# 原生 Chat 记忆自动化对照

审计基线：本地 `Cyrene-Agent` 提交 `cdb46bb5`，上游宿主 `Cyrene-Agent-N` 提交
`836da525b0b98707b050b22bc4446cd324a92f69`。本文件只讨论上游原生 Chat；Work、Code、Learn、
朋友圈和外部渠道不属于当前复现目标。

## 本地版真实行为

- 每 6 个成功轮次提取一次记忆，使用此前最多 2 轮作为只读上下文；待处理轮次跨重启保存。
- 新 L2 写入后先保留原条目，再基于向量候选、词面矛盾、时间、facets 和证据建立 Resolver 队列。
- Resolver 每 5 轮最多处理一项，模型结论可能直接更新状态、创建解决摘要或要求用户澄清。
- 每 20 轮运行向量聚类压缩和 L0/L1 Reflection；压缩候选至少 3 条、余弦阈值 0.85。
- 生命周期每 24 小时最多运行一次：非置顶条目 weight 递减；active 闲置 30 天变 aging，
  aging 闲置 90 天变 archived。召回会刷新 lastAccessedAt。
- 梦境默认关闭；启用后每 10 分钟检查，空闲至少 15 分钟且距上次至少 24 小时才运行。它会做容量
  降级、叙事沉淀及 aging 向量聚类合并；用户恢复活动时取消在途任务。
- DMAE 仅在正式召回/注入链更新工作状态，预检和沙箱使用无副作用预览路径。

## 当前纯插件覆盖

- 原生 Chat 完成事件读取、10 轮提取（另带前 2 轮上下文）、重启续接和下一轮 Prompt Provider 注入。
- 事件模式门禁限定桌面 Chat：Work/Code/Learn 不进入摄取或自动化计数，Prompt Provider 也不向
  这些原生模式或外部渠道注入记忆。旧队列无 mode 时先用官方只读会话列表核验，无法核验则保留队首。
- 独立 L0/L1/L2、来源证据、facets、词面与可选向量检索、Reranker、DMAE 工作集。
- 冲突/重复候选本地扫描、维护收件箱、双条模型复核和用户确认后的归档。
- 双条复核可保存五类 Resolver 关系与结构化变更计划；用户确认后可原子创建双来源总结、更新两侧
  状态并严格撤销。模型计划本身不直接写记忆，需澄清的结果禁止携带变更。
- 手动生命周期预检、应用与严格撤销；人工梦境草稿；人工可撤销压缩。
- 默认关闭的后台复核：每 5 个成功 desktop Chat 轮次最多处理一对未失效候选，默认只保存待确认建议。
- 后台复核可另行授权安全自动应用：仅高置信无变更结论，或带完整双来源总结且两侧均退出当前状态
  的偏好演进；直接冲突、证据不足、低置信和需澄清计划不自动执行，实际变更可严格撤销。
- 默认关闭的后台压缩：每 20 个成功 desktop Chat 轮次最多处理一组 aging 向量候选，默认只保存待确认建议。
- 后台压缩可另行授权安全自动应用：至少 3 条 aging、非置顶、非摘要来源，置信度至少 0.90 且明确
  确认完整覆盖时才原子应用；快照变化、两条来源、旧格式、低置信和覆盖未确认结果均保持待确认，
  实际变更可严格撤销。
- 默认关闭的画像反思：每 20 个成功 desktop Chat 轮次最多请求一次，只用原话能与插件私有
  用户轮次或已核验历史消息证据逐字对上的非摘要、未编辑 L2 提出已有 L0/L1 字段变更；
  候选保留来源快照，人工采用前再次校验、之后可严格撤销。模型自报置信度不构成自动采用依据。
- 默认关闭的每日生命周期扫描：只保存待老化/待归档数量，具体条目仍需重新预检和确认。
- 默认关闭的近似空闲梦境：15 分钟无 desktop Chat 活动且间隔 24 小时后只生成待确认草稿。
- 提取和历史检索只清洗 assistant 派生文本；原始消息不改。注入按完整块预算选择，不截断证据，
  预算外记忆不推进 DMAE 或生命周期命中。宿主现通过 `host:prompt:accepted` 报告单项与总预算
  裁切后的实际接收结果；插件再与成功落盘终态配对，因此超时、丢弃和截断不会误推进状态。

## 纯插件运行验收

已在合成目录中使用上游真实 `PluginManager` 验证：单插件与双插件启停、重启后的待处理状态恢复、
取消与并发门禁、市场 ZIP 替换重载，以及卸载后的 IPC/运行资源清理。市场替换前后的插件私有
`memory-state.json` 保持逐字节一致；卸载只移除插件程序目录，私有数据目录继续保留，全程不调用模型。

完整 Electron 宿主的合成启动也已验证：桌面 Chat 原生记忆开关由宿主读取为关闭，两个插件均实际启用；
测试前后四处已知正式用户数据根的只读哈希一致。此项只证明启动装配，不等同于一轮原生 Chat 的
消息落盘、`turn:finished` 摄取和下一轮 Prompt Provider 注入验收。
2026-09-13 退出原版进程后复测通过；隔离测试入口现先只读检测原版 Electron 进程，检测到仍在运行
即拒绝启动，避免正式数据并发变化使前后哈希失去判别力。无进程与有进程两条预检路径均已实测。
渲染端终态写盘返回空值时现不再上报落盘确认，避免插件把不存在的消息 ID 当作已保存证据；
成功与错误终态均有回归测试。
合成跨层测试进一步覆盖真实 `PluginManager`、桌面轮次协调器与官方 Prompt Provider：
终态未获落盘确认时不摄取；确认后按稳定消息 ID 摄取，下一轮 Chat 注入相关历史，
Work 不注入，全程不调用模型。它仍不是 Electron 渲染端驱动的一轮完整聊天。
完整 Electron 中的合成 Chat IPC 轮次也已通过：使用隔离渲染页的官方 preload API 创建原生 Chat
会话、请求固定回复并写入原生会话存储；未发落盘确认时插件不提前摄取，确认后按消息 ID 摄取，
下一轮宿主构造的上下文含该插件历史。测试进程内替换了模型输出并硬阻断网络，四处正式用户数据根
前后哈希一致。此项验证真实 Electron／preload／IPC／宿主／插件链路，但落盘与确认由合成驱动
调用。补充的隐藏窗口页面测试已让原生 ChatPage 输入框通过 Enter 实际发送合成消息，验证它
自行保存原生助手回复、上报落盘确认，随后插件摄取，下一轮宿主上下文包含带插件专属标记的历史。
两种测试均不用真实模型，也不能证明真实模型的回答质量；第二轮注入的检查仍由合成 IPC 发起。

## 最小宿主门禁（本地工作树，未发布）

`Cyrene-Agent-N` 现在以默认 `native`、可选 `companion` 的桌面 Chat 后端边界代替旧布尔开关。
选择陪伴后端时，该桌面 Chat 轮次不读取原生 L0/L1 或社交原子、不安排旧记忆或社交原子提取、
不写入 `chat_history` RAG，也不向 Chat 提供原生记忆工具；同时允许插件提供稳定人格层、受限本地
主动消息，并旁路投递到本地 Chat 的上游原生主动消息，避免双重发送。门禁在轮次开始固定快照，
运行中修改设置不会造成半轮读写混用。
原生 WorldBook 读取与激活也在陪伴后端旁路，由 companion-chat 的本地内容、V5.1 激活算法和
插件私有状态接管；默认原生后端仍完整使用上游 WorldBook。Work/Code/Learn、外部渠道及原生记忆文件本身保持上游行为；插件记忆的读取、
提取和注入仍需分别启用；微信、飞书主动消息仍走上游原生实现。此边界不隔离应用启动阶段的原生数据迁移或其他模式的写入，
因此不能把它当作“整个主程序只读”或本地版完整复刻的保证。
