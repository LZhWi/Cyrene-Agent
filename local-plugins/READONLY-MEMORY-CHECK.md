# 真实 L2 只读隔离测试

最近复测：2026-09-07。插件实现：companion-memory 0.28.0。下方保留各阶段历史结果，数量不可跨快照直接比较。

## 0.28.0 真实数据只读隔离复测（2026-09-07）

在用户明确授权只读访问后，同时启用真实记忆、聊天证据、正式导入预检、旧向量预检及模型配置
解析五组测试；共 5 个测试文件、33 项测试全部通过。每个源文件均在读取前后进行 SHA-256 校验，
测试没有写源文件或插件存储，没有启动宿主模块，也没有调用模型、Embedding、网络或正式 RAG。
因此未触发 activation、DMAE、lastAccessedAt、访问次数或任何召回统计更新。

首次受限运行因沙箱对 Roaming 目录返回 EPERM 而未能读取文件；获得只读权限后原命令重跑通过。
这属于执行权限问题，不是源数据或插件兼容性失败。本轮仍未执行真实导入，也未启用会把候选发送
给模型的 `CYRENE_REAL_SOURCE_REVIEW`。所有真实正文、ID、密钥与哈希值均未写入报告或命令输出。

## 0.11.0 独立向量迁移与语义查询（2026-09-05）

插件新增默认关闭的 OpenAI-compatible Embedding Provider。官方 Plugin API v1 不提供宿主 Embedding
服务，因此不调用或修改宿主 BGE-M3。密钥仅保存在官方 Secrets；启用后只发送当前查询，测试入口只
发送固定合成文本。HTTPS 和 localhost HTTP 之外的地址、URL内凭据、查询参数与片段均被拒绝。

旧向量生产入口只读预检 memory-store.json 并按 source=user_memory、metadata.l2Id 关联已导入 L2。
正式导入重新核对源 SHA-256，只保存 l2Id 与数值向量，不复制 text 或任何 chat_history；先保存空索引
备份，已有索引或备份时拒绝覆盖。查询维度与索引不一致会明确失败。真实源已通过生产预检入口
只读关联：全库1393条中 chat_history 1299、user_memory 94，94条全部关联当前L2，均为1024维，
无损坏、重复或未匹配L2；memory.json 与向量源前后SHA-256一致。未执行真实导入，
未请求任何 Embedding 服务，也未写用户数据或变更访问/DMAE状态。合成测试覆盖哈希、门禁、备份、
余弦排序及失败不泄露服务端正文。新记忆正文尚未获授权外发，因此暂不自动生成向量。

## 0.10.0 facets 迁移与检索路由（2026-09-05）

生产导入计划现会严格验证并保留L2 facets。普通查询仍要求词面命中，facets只参与排序；仅在
查询同时命中明确记忆类别与“哪些/所有/列出”等清单意图时，允许model来源的同类别条目补充召回。
查询规则不写回分类，未知类别、非法来源、空retrievalKinds或超过3类均关闭导入门禁。

真实memory.json只读预检：106条携带facets，106条结构有效，0条无效，0条待分类；源文件前后
SHA-256一致，源写入0、模型请求0。至此facets不再属于排除项。由于官方Plugin API没有Embedding
服务，本轮没有复制旧向量并声称语义检索可用；查询向量Provider必须在后续独立实现。

## 0.9.0 可撤销空库导入（2026-09-05）

预检通过后新增第二次确认入口。确认时重新读取源并校验预检SHA-256，只允许目标插件记忆为空；
先在插件私有存储写入 memory-state-pre-legacy-import-backup，再单次提交memory-state。源变化、非空目标、
已有备份、版本变化或结构异常均拒绝。状态提交失败时内存仍保持空库，备份保留供人工核对。

旧L0/L1按白名单映射并标为legacy-import；旧L2/evidence标为legacy-unverified。检索、界面和模型复核
不会把旧sourceQuote/quoteSnippet显示成已核对用户原话。nickname不与preferredName猜测合并。
真实数据只进行了预检，没有执行导入：当前可映射L0 4项、L1 2项、L2 107条、evidence 105条；
暂不映射facets 106条、DMAE状态90项、反思日志7条、冲突日志17条及待处理轮次6条。
真实源文件前后哈希一致，源写入和模型请求均为0；提交与失败回滚行为只用N内合成数据验证。

## 0.8.0 正式导入预检入口（2026-09-05）

## 预计算向量的只读候选召回（2026-09-05）

新增 tests/support/semantic-candidates.ts，仅对现有 JSON 向量做内存余弦计算，不初始化正式 RAG、
Embedding Provider、MemoryManager 或 DMAE。查询向量来自对应 user_memory 的现存 L2 向量；
候选只接受 source=chat_history、role=user，且 sessionId、ts、text 能唯一回查到正式聊天中的同一用户消息。
助手向量、无对应会话、文本/时间已陈旧及同时间文本不唯一的记录不进入候选。每条最多8项，附前后各一条上下文。
这是对旧方案的低副作用近似：旧迁移会重新编码 content+triggerText，本轮没有重新编码，因此排序可能不同。

真实数据已经由外部运行状态从昨日105条L2/103条证据增长为107/105；不要跨快照直接比较比例。
当前107条中，95条触发片段逐字唯一匹配、1条规范化唯一匹配、4条压缩总结完成子记忆推导、
7条仍需消歧。7条全部有现存L2向量，每条整理8个语义候选（合计56个候选引用）和最多4个时间邻近候选
（合计28个候选槽位）。候选不是来源结论，尚未经过模型定位与独立复核，也未写入报告中的原文/ID。
7条的语义Top1余弦分数为0.8152～0.9129，平均0.8721；28个时间候选槽位中只有5个同时进入语义Top8。
分数不可直接当置信度，且两路重叠少说明时间邻近仍应作为独立补充，不能只依赖向量排序。
本轮读取 memory.json、一个会话文件及向量库，共3个源文件；测试窗口内前后哈希一致。
写入、正式检索调用、Embedding请求、模型请求、激活值及访问计数更新均为0。

## 方法和限制

仅只读解析原文件，将 L2 最小字段映射到内存中的 PluginStorage；set 和 rootDir 调用直接失败。
不导入原项目运行模块，不启动 Electron，不复制真实数据到 N，不把原文或原始 ID 输出到日志。
测试仅加载插件纯记忆模块，没有模型客户端，且拦截全局 fetch。
没有导入原始聊天档案、L0/L1、Embedding、DMAE、facets、冲突日志或证据全文。
关联证据只统计，不将 triggerText 或 quoteSnippet 自动升级为“已核对的用户逐字原话”。

全文/摘要前缀的自检属于词面索引完整性检查，不是盲测查询集，也不是语义召回质量或本地效果等价证明。
不可注入状态由测试适配层事先保守映射，不代表插件原生已经支持 superseded/merged/有效期。
这不是生产导入器；真实数据没有安装到插件存储。未来正式迁移必须保留状态、证据引用和时间语义，
尤其不能因只读取 sourceQuote 而丢掉独立 evidence 记录，也不能把未知证据补造成事实。
