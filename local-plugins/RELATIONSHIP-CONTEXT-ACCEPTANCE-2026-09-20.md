# 近期关系线索与后端事件边界验收（2026-09-20）

## 范围

本轮只处理桌面 `companion` Chat 的近期关系线索，以及成功轮次事件缺少冻结后端所造成的历史混写
风险。没有启动 Electron，没有读取真实聊天、记忆或 activation 数据；写入范围仅在当前
`Cyrene-Agent-N/.upstream-latest` 工作树。

## 实现与边界

- `host:turn:finished` 的 desktop 分支新增可选 `chatBackend`，值来自轮次开始时冻结的宿主快照，
  不依赖结束时可能已经变化的设置。
- `companion-memory` 只摄取明确标记为 `companion`、成功且存在最终消息落盘 ID 的桌面 Chat；
  `native`、旧宿主缺字段、其他模式、渠道、取消和失败均跳过。
- 近期关系线索直接从插件私有库已保存的成功轮次只读派生，复用本地版的情绪优先级、边界偏好、
  当日摘要和下一轮回应提示。没有第二份关系日志、额外聊天正文或模型调用。
- 派生内容只通过已启用的伴聊记忆 Provider 进入上下文；手动搜索不附加该常驻内容。
