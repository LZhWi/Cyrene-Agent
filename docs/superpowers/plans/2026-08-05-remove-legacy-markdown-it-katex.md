# Remove Legacy markdown-it / katex Dependencies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove `markdown-it`, `katex`, `@mdit/plugin-katex`, `@types/markdown-it` and the now-unused `src/renderer/lib/markdown/` directory by deleting the legacy "detailed doc" popup in the settings page and rewriting the work-flow compatibility table as plain HTML.

**Architecture:** The React chat window has moved to `@ant-design/x-markdown` for message rendering. The only remaining consumer of the old `markdown-it`/`katex` pipeline is `src/renderer/settings/settings.ts`, which renders (1) a small compatibility table and (2) a "detailed doc" popup whose content is `docs/model-work-test/work-flow-test-results-2026-07-24.md`. We drop popup (2) entirely and replace (1) with a hand-written HTML table. This lets us delete `src/renderer/lib/markdown/` and the four packages without touching `src/main/sticker-query.ts` (a separate cleanup tracked for a future plan).

**Tech Stack:** Vitest 4, TypeScript 5.6, Electron renderer (vanilla TS, no React). No new runtime dependencies added.
