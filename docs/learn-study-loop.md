# Learn 复习与视频笔记

Learn 会话的试卷栏新增“学习面板”，仅出现在工作/学习窗口的 Learn 模式。绑定 Vault 后可使用。

## 复习记录

- 普通抽查、正式试卷批改和面板复习作答统一写入 `learn/reviews.md`。Markdown 正文供人阅读，frontmatter 保存逐题记录。原始资料和试卷不被覆盖。
- 面板显示到期数量、待讲评数量、最近作答仍薄弱的知识点和来源状态。`learn/progress.md` 的对话估计单独展示，不把它解释为实测掌握率。
- 点“复习这道题”，实际提交答案后才更新间隔。选择/判断题由宿主判分；简答及由正式填空/解答题转成的复习题保留真实文本，等待模型讲评。用户可在 Learn 对话里说“讲评待批改的复习作答”，模型通过 `learn_review_list` 和 `learn_review_grade` 完成讲评。
- 答错下一天复习；首次答对三天；连续答对后间隔翻倍，最多六十天；再答错重置。此为可解释的简单规则，不宣称实现 FSRS 或经实验验证的遗忘预测。跳过不记账，待讲评不算错。
- 每次作答有独立标识，重复交付不重复计数；并发更新复用 Vault 文件队列。迟到的旧记录按时间归位，不覆盖新的表现。
- 题目分为材料复习 `review` 与应用迁移 `transfer`。迁移题必须附来源路径、完整 SHA-256 和逐字依据；普通抽查可以无校验来源，但面板明确标记“未校验材料来源”。引用存在不证明题目推理或答案正确。
- 来源变化后停止沿用旧题，要求重新核对并出题。
- 正式试卷在命题时固定复习 Vault。旧格式的未批改试卷在首次批改时绑定可信 Vault；已经批改且没有绑定信息的历史试卷不自动猜测归属。试卷评分保存成功而复习写入失败时，工具明确返回警告；打开原 Vault 面板可幂等补写。

## 视频时间轴

1. 把本地课程视频放进当前 Vault，选择“选择 Vault 内视频”。支持浏览器可解码的 MP4/M4V/WebM/OGV，推荐 H.264 MP4 或 WebM。
2. 播放到某个时间点，写笔记并保存。也可导入 Vault 内 UTF-8 SRT/VTT 字幕（最多 2 MiB）。
3. 点击时间轴条目跳转到对应视频位置；播放时高亮当前条目。
4. 笔记存于 `notes/videos/<id>.md`，可在 Obsidian 阅读、供 Learn 读取和整理。字幕与笔记分别标记，重复导入相同字幕不会产生重复条目。

本次实现是本地视频播放、手动时间点笔记与字幕导入。自动录屏、视觉跟拍、语音转写尚未实现。源视频、源字幕保持原样；字幕文本以纯文本呈现。

## 边界与验证

面板写操作携带所展示工作区的版本标识。即使两个 Vault 含有相同题目或视频 ID，重新绑定后旧面板的作答、笔记与字幕导入也会被拒绝。Learn 面板复用已有工作区绑定通知清空旧视图并重新加载；不修改通知发送或 Chat 处理流程。

管理 API 验证工作/学习窗口、主 frame、Learn 会话和可信 Vault。模型工具亦在执行时检查 Learn 模式与工作区，配置覆盖不能绕过。视频由不包含文件路径的随机 URL 映射到已选择的 Vault 文件，支持字节范围读取；工作区重新绑定后旧 URL 不再有效。读写检查已有父目录的真实路径，阻止链接逃逸。

不连接 Chat、聊天记忆、RAG 或 Codex 执行器。学习文件本地存储；选择云端模型时，教学/讲评请求仍遵循现有模型调用规则。

回归测试使用临时 Vault、合成作答、合成字幕与视频；不调用真实模型。原生验证脚本为 `scripts/verify/learn-study-smoke.mjs`。

确定性回归覆盖 13 个文件、121 项测试；主进程编译、preload 构建、renderer 构建及面板类型检查通过。隔离 Electron 验证覆盖真实复习作答、视频解码/播放/跳转、笔记与字幕持久化、重新加载、工作区重绑与旧媒体 URL 撤销。原有正式试卷原生回归通过。Chat、记忆、RAG 与 Codex 的 193 个受保护源码文件哈希保持原样；原生验证中的 111 个原有数据文件没有变化。没有调用真实模型验证命题或讲评准确率。
